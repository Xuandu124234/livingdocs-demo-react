# Currency Utilities

Formatting helpers for monetary values and ratios.

## formatCurrency

`formatCurrency` formats a number as a currency string using `Intl.NumberFormat`,
defaulting to `USD` and the `en-US` locale.

## formatPercent

`formatPercent` formats a ratio between 0 and 1 as a percentage string.

## clamp

`clamp` restricts a number to the inclusive range between `min` and `max`.
