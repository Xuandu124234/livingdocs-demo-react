# Trend Badge

`TrendBadge` renders a small badge that shows the direction of a metric.

## TrendBadgeProps

The `TrendBadgeProps` interface carries the `direction` of the badge and an
optional `label` used both as the visible text and as the tooltip.

## TrendBadge

`TrendBadge` renders a `span` whose class name encodes the direction, so the
badge can be styled with the `trend-badge--up`, `trend-badge--down` and
`trend-badge--flat` classes.
