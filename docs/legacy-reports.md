# Legacy Reports

This page documents the report grid that used to live in the dashboard.

## ReportGrid

`ReportGrid` renders the list of available reports in a table. It accepts a
`reports` prop with the rows to display.

## loadReports

`loadReports` fetches the report list from the API and returns the parsed
result.

## ReportRow

`ReportRow` is a single row of the grid.
